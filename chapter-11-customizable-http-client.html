11可定制的 HTTP 客户端

LangChain4j 默认用 JDK 自带的 HttpClient 调 LLM 提供商 API。但你想加代理 / 自签名证书 / 复杂超时 / 连接池?换底层 HTTP 客户端:JDK / Spring RestClient / Apache HttpClient / OkHttp。本章教你怎么切换 + 怎么注入自定义配置。

一句话定性:LangChain4j 把"调用 LLM API"抽成 HttpClient SPI(服务提供接口)。底层实现可插拔:想用 OkHttp 换 JDK、用 Spring 的连接池、自己塞 SSL 证书 —— 只需实现/选一个 HttpClient Builder 注入 OpenAiChatModel.builder().httpClientBuilder(...)。

1. 业务场景

老板:"我们 AI 服务要部署在内网,但 LLM 在云上。要走代理 / 自签证书 / 复杂超时策略,JDK 默认 HttpClient 满足不了。"

解法:LangChain4j 把 HTTP 调用抽象成 SPI。你要做的只是把底层换成 OkHttp / Apache / Spring RestClient,这些库已经封装了代理 / SSL / 连接池。

5 个 HTTP 客户端能解决的事

  • 代理支持 — 公司内网 → 走 HTTP/SOCKS 代理出去
  • SSL 自定义 — 自签证书 / 公司 CA / 双向认证 mTLS
  • 连接池调优 — 高并发场景复用连接,避免每次握手
  • 超时精细化 — 连接超时 / 读超时 / 写超时分别设置
  • 拦截器 / 过滤器 — 加自定义 Header、记录日志、重试

2. 4 种 HTTP 客户端实现

目前 LangChain4j 提供 4 种 HttpClient 实现(都是 HttpClientBuilder SPI):

实现模块默认场景特点
JdkHttpClientlangchain4j-http-client-jdk纯 Java SDK 默认JDK 自带,零依赖,但功能弱
SpringRestClientlangchain4j-http-client-spring-restclientSpring Boot 默认Spring 生态友好,自动用 Spring 配置
ApacheHttpClientlangchain4j-http-client-apache需要高级特性成熟稳定,代理 / SSL / 池齐全
OkHttpClientlangchain4j-http-client-okhttpAndroid / 高并发轻量,连接池优秀,Kotlin 友好

💡 默认行为:

  • 用 langchain4j-open-ai SDK → 默认 JdkHttpClient
  • 用 langchain4j-open-ai-spring-boot-starter → 默认 SpringRestClient
  • 想换 Apache 或 OkHttp → 加对应依赖,LangChain4j 自动切换(谁在 classpath 优先用谁)

3. 自定义 JDK HttpClient

最常见的自定义:加 SSL 上下文 / 连接超时:

// JDK 原生 Builder
HttpClient.Builder httpClientBuilder = HttpClient.newBuilder()
    .sslContext(myCustomSslContext)      // 自签证书
    .connectTimeout(Duration.ofSeconds(10));

// 包成 LangChain4j 的 JdkHttpClientBuilder
JdkHttpClientBuilder jdkHttpClientBuilder = JdkHttpClient.builder()
    .httpClientBuilder(httpClientBuilder);

// 注入 ChatModel
OpenAiChatModel model = OpenAiChatModel.builder()
    .httpClientBuilder(jdkHttpClientBuilder)
    .apiKey(System.getenv("OPENAI_API_KEY"))
    .modelName("gpt-4o-mini")
    .build();

注意:httpClientBuilder() 接受的是 LangChain4j 自己的 HttpClientBuilder SPI(JdkHttpClientBuilder、SpringRestClientBuilder 等),不是 JDK 的 HttpClient.Builder。两者要互转:把 JDK Builder 用 JdkHttpClient.builder().httpClientBuilder(...) 包装一层。

4. 自定义 Spring RestClient

Spring Boot 6.1+ 提供 RestClient(替代 RestTemplate 的现代 API)。LangChain4j 可以包一层:

// Spring 6.1+ 的 RestClient Builder
RestClient.Builder restClientBuilder = RestClient.builder()
    .requestFactory(new HttpComponentsClientHttpRequestFactory());  // 换底层用 Apache

// 包装给 LangChain4j
SpringRestClientBuilder springBuilder = SpringRestClient.builder()
    .restClientBuilder(restClientBuilder);

OpenAiChatModel model = OpenAiChatModel.builder()
    .httpClientBuilder(springBuilder)
    .apiKey(...)
    .build();

5. 自定义 Apache HttpClient

Apache HttpClient 5 功能最强,适合企业级:

// Apache HttpClient 5 Builder
org.apache.hc.client5.http.impl.classic.HttpClientBuilder apacheBuilder =
    org.apache.hc.client5.http.impl.classic.HttpClients.custom()
        .setConnectionManager(
            PoolingHttpClientConnectionManagerBuilder.create()
                .setMaxConnTotal(200)         // 最大连接数
                .setMaxConnPerRoute(50)        // 每路由最大
                .build())
        .setDefaultRequestConfig(
            RequestConfig.custom()
                .setConnectTimeout(10, TimeUnit.SECONDS)
                .setResponseTimeout(60, TimeUnit.SECONDS)
                .build());

ApacheHttpClientBuilder builder = ApacheHttpClient.builder()
    .httpClientBuilder(apacheBuilder);

OpenAiChatModel model = OpenAiChatModel.builder()
    .httpClientBuilder(builder)
    .apiKey(...)
    .build();

💡 加依赖:用 Apache 实现需加 langchain4j-http-client-apache:

<dependency>
    <groupId>dev.langchain4j</groupId>
    <artifactId>langchain4j-http-client-apache</artifactId>
    <version>1.11.8-beta19</version>
</dependency>

6. 自定义 OkHttp

OkHttp 轻量,Android 标配,Java 后端也常用:

// OkHttp Builder
okhttp3.OkHttpClient.Builder okHttpBuilder = new okhttp3.OkHttpClient.Builder()
    .connectTimeout(10, TimeUnit.SECONDS)
    .readTimeout(60, TimeUnit.SECONDS)
    .proxy(new Proxy(Proxy.Type.HTTP,
                    new InetSocketAddress("proxy.company.com", 8080)))  // 代理
    .addInterceptor(new MyAuthInterceptor());  // 自定义拦截器

OkHttpClientBuilder builder = OkHttpClient.builder()
    .okHttpClientBuilder(okHttpBuilder);

OpenAiChatModel model = OpenAiChatModel.builder()
    .httpClientBuilder(builder)
    .apiKey(...)
    .build();

9. 完整可运行示例(代理场景)

内网部署 + 走公司代理 → 用 OkHttp + 代理配置:

import okhttp3.*;
import java.net.InetSocketAddress;
import java.net.Proxy;
import java.util.concurrent.TimeUnit;

public class ProxiedAiExample {

    public static void main(String[] args) {

        // 1. 配置代理
        Proxy proxy = new Proxy(Proxy.Type.HTTP,
                new InetSocketAddress("proxy.internal.corp", 8080));

        // 2. OkHttp Builder 加代理 + 认证
        String proxyAuth = "Basic " + Base64.getEncoder().encodeToString(
            ("user:pass").getBytes());
        OkHttpClient.Builder okBuilder = new OkHttpClient.Builder()
            .proxy(proxy)
            .proxyAuthenticator((route, response) ->
                response.request().newBuilder()
                    .header("Proxy-Authorization", proxyAuth)
                    .build())
            .connectTimeout(10, TimeUnit.SECONDS)
            .readTimeout(60, TimeUnit.SECONDS);

        // 3. 包成 LangChain4j 的 Builder
        OkHttpClientBuilder lcBuilder = OkHttpClient.builder()
            .okHttpClientBuilder(okBuilder);

        // 4. 注入 ChatModel
        ChatModel model = OpenAiChatModel.builder()
            .httpClientBuilder(lcBuilder)
            .apiKey(System.getenv("OPENAI_API_KEY"))
            .modelName("gpt-4o-mini")
            .build();

        // 5. 正常使用
        String answer = model.chat("Hello via corporate proxy!");
        System.out.println(answer);
    }
}

10. 5 个真实避坑

避坑 1:依赖要加对模块

想用 Apache HttpClient → 必须加 langchain4j-http-client-apache。只加 langchain4j-open-ai 默认只有 JDK。

症状:运行时 NoClassDefFoundError: HttpClientBuilder。

避坑 2:httpClientBuilder() 是 SPI,不是 JDK 的 Builder

传错对象类型 → ClassCastException。记住套路:每个实现都包一层(JdkHttpClient.builder().httpClientBuilder(jdkBuilder)、ApacheHttpClient.builder().httpClientBuilder(apacheBuilder) ...)。

避坑 3:Spring Boot starter 自动选了,自己可能不知道

用 langchain4j-open-ai-spring-boot-starter → 默认 SpringRestClient,不是 JDK。想换 Apache 要在 classpath 加 langchain4j-http-client-apache(优先级不同,看 LangChain4j 内部选择逻辑)。

避坑 4:OkHttp 拦截器 vs HttpClient 拦截器不一样

OkHttp 有 Interceptor(应用层)和 NetworkInterceptor(网络层)。重试逻辑放应用层,日志放网络层(能看到 wire-level 数据)。LangChain4j 内部会加自己的拦截器,你加的在它之前。

避坑 5:代理只对 LLM API 生效

自定义 HTTP 客户端只影响 LangChain4j 调 LLM 的请求,不影响你项目里其他地方的网络调用。配置后记得测试:

String answer = model.chat("Hello");  // 看是否走代理,看日志 / Wireshark

10Spring Boot 集成(国人最熟)

ch01-09 你写的是纯 Java SDK调用,要自己 Builder + 拼 prompt + 管记忆。Spring Boot Starter 把这一切全自动:加依赖 + 写 application.properties + 写 interface + @Autowired 注入。类比 Spring Data JPA、Spring Security。

一句话定性:langchain4j-open-ai-spring-boot-starter + application.properties + @AiService interface = 一个能跑的生产级 AI 后端。LangChain4j 帮你把所有组件(ChatModel / ChatMemory / ContentRetriever / @Tool) 注册成 Spring Bean,直接 @Autowired 用。

1. 业务场景

老板:"我们 Java 后端用 Spring Boot 3 全家桶,AI 这一块能不能也接进来?不要让我每次都 new OpenAiChatModel(...)。"

解法:Spring Boot 的自动装配(auto-configuration)机制。LangChain4j 提供了 langchain4j-*-spring-boot-starter 系列,加依赖 + 写 properties 就好。

5 个 Spring Boot 集成能解决的事

  • 零配置 Bean 注册 — 加 starter,自动有 ChatModel / StreamingChatModel Bean 可注入
  • 配置文件管参数 — application.properties 里写 api-key / model-name,不用硬编码
  • 声明式 AI 服务 — @AiService interface,自动代理(比 AiServices.create() 更优雅)
  • 多模型并存 — OpenAI + Ollama 同时配置,按需注入(@AiService(wiringMode = EXPLICIT))
  • Spring 生态打通 — Micrometer 监控、Actuator 健康检查、Reactor Flux 流式、单元测试 @SpringBootTest

💡 国人友好:Spring Boot 是国内 Java 后端事实标准。LangChain4j 的 Spring Boot 集成做得非常深,几乎是生产首选。如果你们公司是 Spring 技术栈,别用纯 SDK 模式,直接上 Starter。

2. 加依赖(命名约定)

Starter 命名非常规则:langchain4j-{集成名}-spring-boot-starter(Boot 3)或 ...-spring-boot4-starter(Boot 4)。

2.1 Spring Boot 3(3.5+)

<!-- pom.xml -->
<dependency>
    <groupId>dev.langchain4j</groupId>
    <artifactId>langchain4j-open-ai-spring-boot-starter</artifactId>
    <version>1.11.8-beta19</version>
</dependency>

<!-- 如果要用 AI Services 声明式 -->
<dependency>
    <groupId>dev.langchain4j</groupId>
    <artifactId>langchain4j-spring-boot-starter</artifactId>
    <version>1.11.8-beta19</version>
</dependency>

2.2 Spring Boot 4(4.0+)

<!-- 仅 artifactId 不同,版本号保持一致 -->
<dependency>
    <groupId>dev.langchain4j</groupId>
    <artifactId>langchain4j-open-ai-spring-boot4-starter</artifactId>
    <version>1.11.8-beta19</version>
</dependency>

⚠️ 版本对应:Boot 3 starter 用 -spring-boot-starter 后缀,Boot 4 用 -spring-boot4-starter 后缀。不要混搭!Boot 3 项目硬塞 Boot 4 starter → NoSuchMethodError;反之亦然。

3. application.properties 配置

所有模型参数走配置文件,LangChain4j 帮你自动绑定到 Bean:

# application.properties
langchain4j.open-ai.chat-model.api-key=${OPENAI_API_KEY}
langchain4j.open-ai.chat-model.model-name=gpt-4o-mini
langchain4j.open-ai.chat-model.temperature=0.7
langchain4j.open-ai.chat-model.max-tokens=1000
langchain4j.open-ai.chat-model.log-requests=true
langchain4j.open-ai.chat-model.log-responses=true

# 可选:超时配置
langchain4j.open-ai.chat-model.timeout=60s

加完依赖 + 写好 properties,Spring 容器里就有现成的 ChatModel Bean,直接注入:

@RestController
public class ChatController {

    private final ChatModel chatModel;

    public ChatController(ChatModel chatModel) {  // 直接注入
        this.chatModel = chatModel;
    }

    @GetMapping("/chat")
    public String chat(@RequestParam String message) {
        return chatModel.chat(message);
    }
}

4. 3 种 Bean 装配方式

LangChain4j Spring Boot 集成支持三种模式,从简单到复杂。

方式适用场景配置
自动装配单模型 / 单工具默认:加 starter 即可,Spring 自动接线
显式装配多模型 / 多工具,按 interface 选择@AiService(wiringMode = EXPLICIT) + chatModel = "bean名"
事件监听运行时反射看哪些 AI 服务注册了实现 ApplicationListener<AiServiceRegisteredEvent>

4.1 自动元件接线(默认)

Spring 上下文里只要存在以下 Bean,会自动连到 @AiService interface:

// 这些类型 Spring 会自动注入给 @AiService interface
ChatModel              // 普通聊天
StreamingChatModel     // 流式聊天
ChatMemory             // 单聊记忆
ChatMemoryProvider     // 多聊记忆
ContentRetriever       // RAG 检索器
RetrievalAugmentor     // RAG 增强器
ToolProvider           // 工具提供者

// 带 @Tool 注解的类自动被发现(需被 @Component 标记)
@Service
public class BookingTools {

    private final BookingService bookingService;

    public BookingTools(BookingService bookingService) {
        this.bookingService = bookingService;
    }

    @Tool
    public Booking getBookingDetails(String bookingNumber,
                                     String customerName,
                                     String customerSurname) {
        return bookingService.getBookingDetails(bookingNumber, customerName, customerSurname);
    }
}

💡 神奇之处:你写一个 interface + @AiService,LangChain4j 自动找上下文里的 ChatModel、ChatMemory、BookingTools(@Component + @Tool),全部连起来生成代理类。

4.2 显式元件布线(多模型场景)

当有多个 AI 服务,每个用不同 ChatModel 时,用 @AiService(wiringMode = EXPLICIT) 显式指定。

Step 1:在 properties 里配多个模型

# application.properties

# OpenAI(快,贵)
langchain4j.open-ai.chat-model.api-key=${OPENAI_API_KEY}
langchain4j.open-ai.chat-model.model-name=gpt-4o-mini

# Ollama(本地,免费)
langchain4j.ollama.chat-model.base-url=http://localhost:11434
langchain4j.ollama.chat-model.model-name=llama3.1

Step 2:用 @AiService 指定哪个 interface 用哪个 Bean

@AiService(wiringMode = WiringMode.EXPLICIT, chatModel = "openAiChatModel")
interface OpenAiAssistant {
    @SystemMessage("You are a polite assistant")
    String chat(String userMessage);
}

@AiService(wiringMode = WiringMode.EXPLICIT, chatModel = "ollamaChatModel")
interface OllamaAssistant {
    @SystemMessage("你是一个本地助手")
    String chat(String userMessage);
}

Step 3:在 Controller 注入

@RestController
public class MultiModelController {

    private final OpenAiAssistant openAiAssistant;
    private final OllamaAssistant ollamaAssistant;

    public MultiModelController(OpenAiAssistant openAiAssistant,
                                OllamaAssistant ollamaAssistant) {
        this.openAiAssistant = openAiAssistant;
        this.ollamaAssistant = ollamaAssistant;
    }

    @GetMapping("/cloud-chat")
    public String cloudChat(String msg) {
        return openAiAssistant.chat(msg);  // 走 GPT
    }

    @GetMapping("/local-chat")
    public String localChat(String msg) {
        return ollamaAssistant.chat(msg);  // 走本地 Llama
    }
}

生产实战:简单对话 → 本地 Ollama(省钱);复杂推理 → OpenAI(质量)。一个 Spring Boot 项目两个模型共存,按需路由。

4.3 监听 AI 服务注册事件

想在运行时反射看哪些 AI 服务已注册?实现 ApplicationListener<AiServiceRegisteredEvent>:

@Component
class AiServiceRegisteredEventListener
        implements ApplicationListener<AiServiceRegisteredEvent> {

    @Override
    public void onApplicationEvent(AiServiceRegisteredEvent event) {
        Class<?> aiServiceClass = event.aiServiceClass();
        List<ToolSpecification> toolSpecs = event.toolSpecifications();

        System.out.println("AI 服务注册:" + aiServiceClass.getSimpleName());
        System.out.println("  工具数:" + toolSpecs.size());
        toolSpecs.forEach(t ->
            System.out.println("  - " + t.name() + ": " + t.description())
        );
    }
}

用途:管理后台 / 调试面板 / 动态文档生成。启动时打印所有 AI 服务 + 工具清单。

5. 流式响应(Reactor Flux)

Spring Boot 项目常用 Reactor,LangChain4j 支持 Flux<String> 作为返回类型:

@AiService
interface StreamingAssistant {
    @SystemMessage("You are a polite assistant")
    Flux<String> chat(String userMessage);  // 流式
}
<!-- 需要 langchain4j-reactor 模块 -->
<dependency>
    <groupId>dev.langchain4j</groupId>
    <artifactId>langchain4j-reactor</artifactId>
    <version>1.11.8-beta19</version>
</dependency>

SSE 端点用 Flux 直接返回给前端:

@GetMapping(value = "/stream-chat", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
public Flux<String> streamChat(String msg) {
    return streamingAssistant.chat(msg);
}

6. 可观测性(Micrometer 监控)

生产环境要监控 AI 调用:耗时、token 数、错误率。LangChain4j 提供 ChatModelListener 拦截器:

6.1 加依赖

<!-- Micrometer 集成 -->
<dependency>
    <groupId>dev.langchain4j</groupId>
    <artifactId>langchain4j-micrometer-metrics</artifactId>
    <version>1.11.8-beta19</version>
</dependency>

<!-- Spring Boot Actuator -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-actuator</artifactId>
</dependency>

6.2 注册监听器

@Configuration
class MetricsConfig {

    @Bean
    ChatModelListener chatModelListener() {
        return new ChatModelListener() {

            private static final Logger log = LoggerFactory.getLogger(ChatModelListener.class);

            @Override
            public void onRequest(ChatModelRequestContext req) {
                log.info("→ 请求:{}", req.chatRequest().messages());
            }

            @Override
            public void onResponse(ChatModelResponseContext resp) {
                log.info("← 响应:{}", resp.chatResponse().aiMessage().text());
            }

            @Override
            public void onError(ChatModelErrorContext err) {
                log.error("✗ 异常", err.error());
            }
        };
    }
}

加上 langchain4j-micrometer-metrics 后,LangChain4j 自动把 token 数、耗时接到 Micrometer。/actuator/metrics 能看到 langchain4j.tokens、langchain4j.duration 等指标。

7. 测试(@SpringBootTest)

集成测试 @SpringBootTest,LangChain4j 提供 langchain4j-spring-boot-starter 测试支持:

import static org.assertj.core.api.Assertions.*;

@SpringBootTest
class AssistantIT {  // IT = Integration Test

    @Autowired
    Assistant assistant;

    @Test
    void should_answer_simple_question() {
        String answer = assistant.chat("What is the capital of France?");
        assertThat(answer).containsIgnoringCase("Paris");
    }
}

💡 Mock 测试:不想每次跑测试都打真实 LLM?用 @MockBean 替换 ChatModel:

@SpringBootTest
class AssistantTest {

    @MockBean
    ChatModel chatModel;

    @Autowired
    Assistant assistant;

    @Test
    void should_call_chat_model() {
        String mockAnswer = "Paris";
        @SuppressWarnings("unchecked")
        ChatResponse resp = ChatResponse.builder()
                .aiMessage(AiMessage.from(mockAnswer))
                .build();
        when(chatModel.chat(any(ChatRequest.class))).thenReturn(resp);

        String answer = assistant.chat("capital of France?");
        assertThat(answer).isEqualTo("Paris");
        verify(chatModel).chat(any(ChatRequest.class));
    }
}

10. 5 个真实避坑(从官方文档 + 生产事故)

避坑 1:Boot 3 / Boot 4 starter 不能混

项目是 Spring Boot 3.x → 必须用 -spring-boot-starter 后缀;

项目是 Spring Boot 4.x → 必须用 -spring-boot4-starter 后缀。

混搭症状:NoSuchMethodError、ClassNotFoundException。LangChain4j 的 Boot 集成强依赖 Spring 版本(有些 API 只在 Boot 4 有)。

避坑 2:api-key 别硬编码

永远用 ${OPENAI_API_KEY} 占位符,从环境变量读。提交到 git 仓库的 key = 跑路风险。生产建议上配置中心(Nacos / Apollo / Vault)。

避坑 3:log-requests / log-responses 生产慎开

开发环境开起来排查 prompt 很爽,但生产环境会把用户对话完整打日志(含隐私 / PII)。要么关掉,要么加 MDC 过滤敏感字段。

避坑 4:timeout 单位

timeout=60s 是 Duration 解析,可用 30s / 2m / PT60S(ISO-8601)。不能写 60000(会被解析成 60000 毫秒 = 60 秒,但代码读起来不直观)。

避坑 5:@AiService interface 必须能被 Spring 扫到

interface 放在 com.example.app(主类同包或子包)就没问题。放错包 → Spring 扫不到 → 启动报 NoSuchBeanDefinitionException。要么用 @ComponentScan("com.example") 显式指定。
